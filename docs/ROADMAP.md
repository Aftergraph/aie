# AIE Roadmap

## Current: v0.4 external interoperability

- **S1.1 / S1.2 — MCP + SPIRE:** external official MCP conformance through direct, SPIFFE, and AIE paths; live SVID/trust rotation.
- **S2 — A2A:** official A2A TCK over supported transports and task lifecycle semantics.
- **S3 — Policy independence:** OPA/Cedar parity over the portable AIE decision corpus.
- **S4 — Federation chaos:** partitions, duplicates, out-of-order revocations, restart, and clock skew.
- **S5 — Independent implementation:** a second implementation not derived from the Python runtime.

## Promotion to Draft 0.4 Interop Draft

Promotion requires all MUST gates above to be externally reproducible. Candidate Standard maturity additionally requires multi-maintainer governance, interoperability across independent implementations, security/privacy review, and stable extension/registry policy.
